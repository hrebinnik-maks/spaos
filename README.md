# SPAOS

Лабораторні роботи з дисципліни "Системне програмування та адміністрування операційних систем".

## Вміст

- `count_files.sh` — Bash-скрипт для підрахунку файлів у директорії.

## Можливості

- Підрахунок звичайних файлів
- Підрахунок файлів із заданим розширенням
- Рекурсивний підрахунок файлів
- Обчислення загального розміру файлів

## Використання

```bash
chmod +x count_files.sh
./count_files.sh
./count_files.sh /home/user txt
```
